### 👨‍💻 About Me

Hi there! I'm **Abdul Rehman**, a passionate **Frontend & Full-Stack MERN Developer** based in Pakistan. I build modern, user-friendly web applications and explore smart **AI & workflow automations** using tools like n8n, Webhooks, and LLM services.

I completed the Web and Mobile App Development program at **Saylani Mass IT Training (SMIT)**, gaining strong hands-on experience in modern frontend development, full-stack web architectures, and backend integrations.

---

### 🚀 What I Do

- **Frontend Development:** Build responsive UIs with **React.js**, **Tailwind CSS**, and **Material UI (MUI)** with effective state management.
- **MERN Stack Applications:** Develop complete web solutions using **Node.js**, **Express.js**, **MongoDB**, and **Firebase**.
- **AI Automation:** Connect applications with automated workflows, email processing pipelines, and AI models via **n8n** and **REST APIs**.
